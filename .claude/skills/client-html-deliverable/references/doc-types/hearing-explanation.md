# 文書タイプ: ヒアリング回答・説明資料（hearing-explanation）

客先ヒアリングへの回答や、特定論点の説明資料。特定時点の質問群に対する回答として完結する、比較的短期の成果物。

## 章立て

原稿のQ&A単位をそのまま章にする。1章＝1論点前後（複数の関連質問をまとめても良い）。

## 本文パターン

`template.html`の`section.chapter`以下がこの文書タイプの本文例そのもの。追加の変換は不要で、原稿の構成に合わせて`article.qa`を複製・差し替えるだけで良い。

- `article.qa` 1つ＝質問1つ（`<h3><span class="qnum">Q番号</span> 見出し</h3>`）
- 客先の実発言がある場合は`blockquote.client-answer`で引用してから説明に入る（要約せず、原文をそのまま引用する）
- 説明本文の後、該当すれば`callout warn`（既知のリスク）→`callout ask`（こちらから確認したいこと）の順で配置する。両方要らない場合は省略可
- 処理フローの説明が要る質問は`diagram > flow-steps`、UIイメージの説明が要る質問は`ui-frame`＋4パターンのいずれかを使う（`SKILL.md`の「UIモックアップの4パターン」参照）

## 使う機能コンポーネント

通常は不要。原稿が大きく（20問超など）1ファイルでは長すぎる場合のみ`references/components/multifile-packaging.md`を検討する。
